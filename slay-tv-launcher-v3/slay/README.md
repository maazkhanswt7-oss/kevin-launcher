# Slay Launcher (TV)

Tiny, dependency-free Android TV launcher. Java only, no libraries.

## Get the APK (no Android Studio needed)
1. Create a new GitHub repo, upload everything in this folder (keep the .github folder).
2. Open the repo -> Actions tab -> "Build APK" runs automatically (or press Run workflow).
3. When it turns green, open the run -> Artifacts -> download slay-launcher-apk -> unzip -> app-debug.apk.

## Install on the TV
1. Copy app-debug.apk to the USB drive.
2. On the TV, open it from a file manager (VLC / Media), allow "Unknown sources".
3. Open "Slay Launcher" from the apps list. Press Home: if the TV asks which launcher, pick Slay Launcher.

## Use
- OK = open app, hold OK = pin/unpin to Favorites.
- Your original launcher shows up as a tile, so you can always get back.

## Uninstall
Settings -> Apps -> Slay Launcher -> Uninstall. The stock launcher is never touched.
