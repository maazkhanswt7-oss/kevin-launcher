# Kevin: iPhone-style TV launcher

Upload everything in this folder to the TOP LEVEL of a GitHub repo (keep .github).
The "Build APK" action builds it; download the `kevin-apk` artifact -> app-debug.apk.

Install on TV from USB, open Kevin, press Home and choose Kevin as launcher.

Phone remote: on the TV open the "Phone Remote" tile (or read the footer) for the address + PIN,
then open that address on a phone on the same Wi-Fi.
LED strip: needs a Wi-Fi strip running WLED; enter its IP on the phone page.
